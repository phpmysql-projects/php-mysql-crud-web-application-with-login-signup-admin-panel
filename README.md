# PHP MySQL CRUD Web Application with Login & Signup System

A complete PHP MySQL CRUD web application with login, signup, admin panel, dynamic form builder, charts dashboard, and 40+ features — built from scratch.

  ## ✨ Features

  - ✅ Login & Signup with CSRF Protection
  - ✅ Email OTP Verification
  - ✅ Google OAuth 2.0 Authentication
  - ✅ Forgot & Reset Password
  - ✅ Remember Me (30-Day Token)
  - ✅ Role-Based Access Control (Admin/User)
  - ✅ Dynamic CRUD Form Builder
  - ✅ 22 Field Types (Text, Dropdown, File Upload, Signature, Camera, QR Scanner, GPS & More)
  - ✅ AI-Powered Form Generation (Gemini API)
  - ✅ Appointment Booking System
  - ✅ Conditional Field Visibility
  - ✅ Dependent Dropdowns
  - ✅ Multi-Step Forms
  - ✅ Public Forms with Password Protection
  - ✅ Dynamic Charts (Bar, Pie, Doughnut, Line, Area)
  - ✅ DataTables with CSV/PDF/Print Export
  - ✅ Activity Audit Logging
  - ✅ Session Management with Force Logout
  - ✅ SMTP Email Notifications
  - ✅ Maintenance Mode
  - ✅ Theme Customization (Dark/Light Mode)
  - ✅ Mobile Responsive Design
